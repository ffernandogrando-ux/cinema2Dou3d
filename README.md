# cinema2Dou3d

Canal de animação em stickman (2D + cenários 3D) com histórias de **gênero de filme** (assalto, loop temporal, jogo mortal, investigação), em que a reviravolta revela uma crítica social, e as homenagens a filmes são as pistas.

- Formato: `FORMATO_CINEMA.md`
- Estado e próximo passo: `ESTADO.md`
- Peles de gênero: `estilos/`
- Motor (render com Playwright + three.js): `motor/` (`npm install` antes do primeiro render)

Motor herdado do projeto anima-ovitinho (canal Regra Torta).
